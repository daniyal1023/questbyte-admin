# Questbyte Labs · Wallpaper Console

Admin page for the HD Wallpapers app. Static HTML, talks to Supabase directly.
Deployed with GitHub Pages; writes require signing in as the admin account
(enforced by row-level security in Supabase, not by this page).

Source of truth lives in the app repo at `admin/index.html` — copy it to `docs/index.html` here to redeploy.
